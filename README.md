# Рецепты · Форма 1

Десктоп-приложение для заполнения и печати рецептурных бланков формы 1 (Беларусь).

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Обновление

В разделе **Настройки** есть кнопка проверки обновлений с GitHub.
Если вы клонировали репозиторий через `git`, обновление выполняется через `git pull`.
Иначе приложение скачает архив с ветки `main`.

Репозиторий: https://github.com/DocKavetski/recipies
