# Рецепты · Форма 1

Десктоп-приложение для заполнения и печати рецептурных бланков формы 1 (Беларусь).

Репозиторий: https://github.com/DocKavetski/recipie

## Что встроено в программу

- Штамп организации и УНП
- ФИО врача по умолчанию
- Макет бланка рецепта (форма 1)
- Справочник препаратов

Локальные данные **не** хранятся в GitHub и не затираются при обновлении:

- `data/settings.json`
- `data/app.db` (история, пользовательские шаблоны)
- `data/autosave.json`

## Запуск из исходников

```bash
pip install -r requirements.txt
python main.py
```

## Сборка для рабочего ПК

```powershell
./scripts/build_portable.ps1
```

Готовая папка: `dist/Recepty/` (запуск `Recepty.exe`).  
Архив для переноса: `dist/Recepty-portable.zip`.

## Обновление

В разделе **Настройки**:

1. **Проверить обновления** — сравнение с GitHub (`main` / Release).
2. **Обновить приложение** — для git-клона: `git pull`; для сборки: скачивание zip-релиза или архива ветки.

Правки можно вносить через Cursor (в т.ч. мобильный): изменить код → push в `main` → на работе нажать «Обновить».

Для релизной сборки:

```bash
git tag v1.1.0
git push origin v1.1.0
```

GitHub Actions соберёт `Recepty-portable.zip` и приложит к Release.
