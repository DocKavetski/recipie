Наличие в Минске
Данные с tabletka.by по аптекам Минска. На вкладке «Рецепт» колонка «Наличие» обновляется сама при добавлении препарата. Здесь — массовая проверка справочника.
  1. Откройте вкладку Рецепт, найдите препарат и добавьте его — справа появится статус «Есть / Мало / Нет».
  2. Или нажмите Проверить справочник ниже: приложение опросит tabletka.by по первым препаратам каталога (может занять 20–60 сек).
